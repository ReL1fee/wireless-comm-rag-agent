# 通信基础理论

## 1. 香农信道容量定理

C = B · log₂(1 + S/N)

其中 C 为信道容量（bps），B 为带宽（Hz），S/N 为信噪比（线性值，非dB）。

这是通信系统的理论上限，任何实际系统的传输速率都不可能超过香农容量。公式说明：
- 增大带宽可线性提高容量
- 增大信噪比可对数提高容量（效率较低）
- 要成倍提高容量，最有效的方式是增加带宽或使用MIMO

## 2. 奈奎斯特准则

在带宽为B的理想基带信道中，无码间干扰的最大符号速率为 2B Baud（波特）。
- 升余弦滚降滤波器用于实现无ISI传输
- 滚降因子 α 决定带宽扩展

## 3. 调制方式

### 3.1 BPSK
二相移键控，每个符号1比特，抗噪声能力最强，适用于低SNR场景

### 3.2 QPSK
四相移键控，每个符号2比特，是BPSK和QAM之间的折中

### 3.3 QAM（正交幅度调制）
同时利用幅度和相位，高阶QAM（16QAM/64QAM/256QAM）传输更多bit/符号
- 阶数越高，频谱效率越高，但抗噪能力越差
- 5G支持最高1024QAM

## 4. 信噪比与误码率

- SNR_dB = 10 · log₁₀(S/N)
- 对于AWGN信道下的BPSK：BER = 0.5 · erfc(√(E_b/N_0))
- E_b/N_0 = SNR × (B/R_b)，其中 R_b 为比特速率

## 5. 信道模型

- AWGN信道：仅加性高斯白噪声，理论分析基准
- 瑞利衰落：多径丰富无直视路径，城区环境典型模型
- 莱斯衰落：存在直射路径，郊区/室内环境

## 6. 多址技术

| 技术 | 原理 | 代表系统 |
|------|------|----------|
| FDMA | 频分多址 | 1G |
| TDMA | 时分多址 | 2G GSM |
| CDMA | 码分多址 | 3G WCDMA |
| OFDMA | 正交频分多址 | 4G LTE / 5G NR |
| NOMA | 非正交多址 | 5G/6G候选技术 |

## 7. 5G三大应用场景

- eMBB（增强移动宽带）：大带宽、高速率，如4K/8K视频、VR
- URLLC（超可靠低时延通信）：1ms级时延、99.999%可靠性，如自动驾驶、远程手术
- mMTC（大规模机器通信）：百万级连接密度，如物联网传感器
