# OFDM（正交频分复用）技术详解

## 1. 基本概念

OFDM（Orthogonal Frequency Division Multiplexing）是一种多载波调制技术。其核心思想是将高速数据流分配到多个正交的子载波上并行传输，每个子载波上的数据速率降低，符号周期延长，从而有效对抗频率选择性衰落和码间干扰。

## 2. 正交性原理

OFDM中子载波频率满足：f_k = f_0 + k·Δf，其中 Δf = 1/T_s（T_s为一个OFDM符号周期）。

两个子载波在符号周期 T_s 内的内积为零：∫_0^{T_s} e^{j2πf_m t} · e^{-j2πf_n t} dt = 0 （m ≠ n 时）。

这意味着虽然子载波在频域上有重叠，但由于正交性，在接收端可以通过积分完全分离。

## 3. 循环前缀（CP）

循环前缀是将OFDM符号尾部的一段数据复制到符号前端。其作用包括：
- 消除符号间干扰（ISI）：当前一个符号的多径延迟不超过CP长度，就不会影响当前符号的FFT窗口
- 将线性卷积转换为循环卷积：便于频域均衡
- 代价是功率和频谱效率的损失，CP长度通常占符号周期的1/4到1/8

## 4. FFT实现

OFDM的调制/解调可以通过IFFT/FFT高效实现：
- 发送端：IFFT将频域符号转换到时域
- 接收端：FFT将时域信号转换回频域
- N点FFT的复杂度为O(N log N)，远低于传统实现

## 5. 子载波间隔

不同通信系统采用不同的子载波间隔：
- LTE：15 kHz
- 5G NR：15/30/60/120/240 kHz（灵活参数集）
- 子载波间隔越大，对多普勒频移的容忍度越高，适合高速移动场景

## 6. 优缺点分析

优点：
- 有效对抗频率选择性衰落
- 高频谱效率（子载波可重叠）
- FFT高效实现
- 易于与MIMO结合

缺点：
- 峰均功率比（PAPR）高，对功放线性度要求高
- 对频率偏移敏感（破坏子载波正交性）
- CP带来频谱效率损失
